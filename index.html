Vibe Coding의 특징

❖ 직관과 AI 동반 성장

▪ 자연어 기반 개발
  • 영어 혹은 모국어의 자연어 프롬프트 사용
  • 텍스트 설명을 통해 원하는 결과를 직접 유도
  • 구문 오류(Syntax Error) 고민 없는 개발 방식

  • 코드의 내부 작동 원리 완전 이해 생략 가능
  • 보일러플레이트 자동 생성 기반 속도 극대화
  • 구조화된 코드 조각 및 API 융합 활용
▪ 직감적 접근
  • 사전의 엄밀한 논리 설계 단계 최소화
  • 직감과 개발적 느낌에 의존한 빠른 프로토타이핑
  • 반복 피드백을 통한 즉흥적이고 유연한 확장

▪ 5단계: 배포 및 운영

Chapter 01

🧠 AI Agent란?

LLM을 두뇌로, 도구(Tool)를 손발로 — 스스로 계획하고 실행하는 소프트웨어

"AI Agent = LLM + Planning + Tool Use + Memory + Action"
🧩
Planning

목표를 단계로 분해하고 순서를 결정

🔧
Tool Use

파일 읽기/쓰기, 검색, 코드 실행

🔁
Feedback Loop

결과를 보고 다음 행동을 조정

AI Agent는 단순히 텍스트를 생성하는 게 아니라, 스스로 계획을 세우고 도구를 사용해서 목표를 달성합니다.

🆚 챗봇 vs AI Agent

기존 챗봇
  • 단일 질문 → 단일 응답
  • 컨텍스트가 짧음
  • 도구 사용 불가
  • 사람이 결과를 직접 실행해야 함
  • 반복 작업 자동화 어려움
AI Agent
  • 목표 설정 → 자율적 멀티스텝 실행
  • 장기 컨텍스트 & 메모리
  • 코드 실행, 파일 I/O, 웹 검색
  • 스스로 결과를 확인하고 수정
  • 복잡한 워크플로우 완전 자동화

Devin / SWE-agent

🔄 워크플로우 변화

Before → After: AI Agent 통합 전후 비교

BEFORE (기존)
  1. 요구사항 파악
  2. 직접 구글링 & 문서 검색
  3. 보일러플레이트 직접 작성
  4. 수동 테스트 & 디버깅
  5. 테스트 코드 별도 작성
  6. 팀원 코드 리뷰 요청 대기
  7. 문서 수동 업데이트
AFTER (AI Agent)
  1. 요구사항 → Agent에게 전달
  2. Agent가 자율적으로 검색 & 분석
  3. 코드 스캐폴딩 자동 생성
  4. Agent가 코드 실행 & 오류 자동 수정
  5. 테스트 자동 작성 & 실행
  6. PR 자동 리뷰 (1차)
  7. 문서 자동 갱신

Chapter 05

🚀 실전 사례: CRUD API 자동 생성

프롬프트 예시
Spring Boot 3.2 + JPA + PostgreSQL 환경에서
Product 엔티티에 대한 REST API를 생성해줘.

요구사항:
- GET /products (페이지네이션)
- POST /products (유효성 검사 포함)
- PUT /products/{id}
- DELETE /products/{id} (소프트 삭제)

레이어: Entity, Repository, Service, Controller, DTO
예외처리: GlobalExceptionHandler 사용
테스트: 각 레이어 단위 테스트 포함
결과 — 약 8개 파일, 400+ 라인의 코드를 3분 이내에 생성 + 테스트 통과

🐛 실전 사례: 버그 자동 수정

버그 시나리오
// 기존 코드 — N+1 문제 발생
List<Order> orders = orderRepository.findAll();
orders.forEach(o -> {
    System.out.println(o.getUser().getName()); // 쿼리 N번 실행!
});
Agent 수정 결과
// Agent 제안 — Fetch Join으로 해결
@Query("SELECT o FROM Order o JOIN FETCH o.user")
List<Order> findAllWithUser();

// 쿼리 1번으로 최적화 완료
